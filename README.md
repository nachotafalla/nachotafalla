### 🪨 Clearly

A calm desktop journaling app focused on private reflection, simple writing, and optional AI-assisted thinking.

Clearly is built around the idea that journaling should stay personal and user-led. AI can help you reflect, but it should never judge, diagnose, score, or define your thoughts for you.

This is currently a **beta release**, so there may still be bugs, missing polish, and fixes needed.

I built it using **Tauri, React, TypeScript, and Vite**, with a privacy-first and local-first product vision.

**Tools:** Tauri · React · TypeScript · Vite · UI/UX · Product design

📌 [View project](https://clearlyjournal.com)

### 🏦 Neobank Risk Intelligence

A fintech fraud analytics case study on **account-opening risk** and **manual review prioritization**.

I used **SQL, Python, statistics, machine learning, time-aware validation, model interpretation, and business analysis** to study how a neobank could prioritize suspicious applications when manual review capacity is limited.

**Tools:** SQL · Python · pandas · scikit-learn · matplotlib

📌 [View project](https://github.com/nachotafalla/neobank-risk-intelligence)

### 🌙 Dimmer

An open-source Raycast extension that lets Mac users dim every connected display beyond its minimum hardware brightness.

Dimmer uses a lightweight, click-through overlay and provides quick commands, assignable hotkeys, a brightness-style HUD, and a menu bar control. Everything runs locally and no usage data is collected.

**Tools:** Raycast API · TypeScript · React · Swift · AppKit · macOS

📌 [View project](https://github.com/nachotafalla/dimmer)

### 📺 Where Was I?

A Flask web app built as my **CS50 final project**.

**Tools:** Python · Flask · SQLite · HTML/CSS · Jinja · API integration

📌 [View project](https://github.com/nachotafalla/where-was-i)
